# Support

## Getting Help

Thank you for using Obsidian Honor Coders projects!

### Documentation

Start with the project's README and documentation:

- **README.md** — Overview and quick start
- **GETTING_STARTED.md** — Detailed setup instructions
- **CONTRIBUTING.md** — How to contribute
- **Architecture docs** — Design and structure

### Questions & Discussions

- Open a **Discussion** in the repository (if enabled)
- Check existing **Issues** for similar questions
- Review closed issues for solutions

### Reporting Issues

Found a bug or want a feature?

- **Bug reports**: Use the [Bug Report](/.github/ISSUE_TEMPLATE/bug_report.md) template
- **Feature requests**: Use the [Feature Request](/.github/ISSUE_TEMPLATE/feature_request.md) template
- **Security issues**: See [SECURITY.md](/.github/SECURITY.md) for responsible disclosure

### Code of Conduct

All interactions in our community are governed by our [Code of Conduct](/.github/CODE_OF_CONDUCT.md). Please be respectful and constructive.

### Contact

For organizational inquiries, refer to the `CODEOWNERS` file in the repository.
